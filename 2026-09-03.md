Goal build out transponder system:
- Universal system with interchangable slots for each connection type, bare TCP, unix socket, websocket, http, shm, communicators socket, beacon. with dynamic logic to assess which range of connection types are relevant based on IP or lack thereof.
- The control flow of the universal system is not yet designed in one place, but rather across several programs and needs to be united.
- Additionally the rules for each connection type slot must be codified. 

This is where core.py comes in. What we will probably end up with is three levels of abstraction, core.py inhabiting the highest level, the universal nuts and bolds connections inhabiting the middle level and the swapable connection type slots inhabiting the lowest level.
- due to prefix efficiency, these level of abstraction will probably optimally inhabit the same file in internal_imports
